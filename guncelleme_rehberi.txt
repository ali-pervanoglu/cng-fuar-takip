SENARYO A: Bir aşama tamamlandığında dashboard'u güncelle
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

ADIM 1 — DBeaver'da SQL çalıştır
──────────────────────────────────
Hangi fuar, hangi aşama bittiyse aşağıdaki şablonu doldur:

  UPDATE pipeline_durum
  SET [ASAMA_ADI] = 'D',
      guncelleyen = 'ali'
  WHERE fuar_id = (
    SELECT fuar_id FROM pipeline_fuar_meta
    WHERE fuar_kod = '[FUAR_KODU]'
  );

Aşama adları:
  temizlik_durum   → Temizlik & Modelleme tamamlandı
  db_durum         → DB'ye yükleme tamamlandı
  mx_durum         → MX Sorgu tamamlandı
  mev_durum        → MEV Doğrulama tamamlandı
  email_durum      → Email listesi hazır
  sms_durum        → SMS listesi hazır

Fuar kodları:
  aysaf_2026_tr         → AYSAF 2026 Yurt İçi
  aysaf_2026_yd         → AYSAF 2026 Yurt Dışı
  aysad_2026_uye        → AYSAD 2026 Üye listesi
  paintist_2026_ydz     → PaintIstanbul 2026 YDZ
  turkkompozt_2026_ydk  → Turkkompozt 2026 YDK
  paintist_2026_ydk     → PaintIstanbul 2026 YDK
  puexpo_2026_ydk       → Puexpo 2026 YDK

Örnek — AYSAD MX sorgusu bitti:
  UPDATE pipeline_durum
  SET mx_durum = 'D', guncelleyen = 'ali'
  WHERE fuar_id = (
    SELECT fuar_id FROM pipeline_fuar_meta
    WHERE fuar_kod = 'aysad_2026_uye'
  );

✅ Kontrol: "1 row affected" yazmalı.

DBeaver'da çalıştır:
  SELECT fuar_ad, fuar_alt,
         temizlik_durum, db_durum, mx_durum,
         mev_durum, email_durum, sms_durum,
         kayit_sayisi, tamamlanma_pct
  FROM v_pipeline_ozet;

ETL geçmişine bak:
  SELECT * FROM pipeline_etl_log ORDER BY calisma_ts DESC LIMIT 10;

Sadece hataları gör:
  SELECT * FROM pipeline_etl_log WHERE durum = 'HATA' ORDER BY calisma_ts DESC;

HATA: "DB bağlantı hatası"
  → .env dosyasını aç (Notepad ile)
  → DB_HOST=localhost, DB_NAME=cng_expo, DB_USER=postgres doğru mu?
  → PostgreSQL servisi çalışıyor mu?

HATA: "index.html bulunamadı"
  → CMD'de şunu çalıştır:
    copy index_v2.html index.html
  → guncelle.bat'ı tekrar çalıştır

HATA: "GitHub push başarısız / 403"
  → GitHub Personal Access Token süresi dolmuş olabilir
  → Yeni token oluştur (github.com → Settings → Developer settings)
  → CMD'de token'ı güncelle:
    git remote set-url origin https://ali-pervanoglu:YENI_TOKEN@github.com/ali-pervanoglu/cng-fuar-takip.git

Dashboard güncellenmiyor:
  → Ctrl+F5 ile cache temizleyerek yenile
  → 1-2 dk bekle (GitHub Pages gecikmesi)

Görev adı : CNG_Fuar_Pipeline_ETL
Zamanlama : Her 10 dakikada bir (tam mod: sayılar + KPI + benzersiz kişi)
Komut     : python etl_pipeline.py   (tam yol: anaconda3\python.exe)

Her çalışmada:
  → v_pipeline_ozet okunur (34 kart), sayılar ve KPI'lar güncellenir
  → data.json yazılır (içerik değişmediyse yazılmaz / commit atılmaz)
  → Değişiklik varsa GitHub'a push edilir, Pages birkaç dakikada yayınlar

Tek manuel adım: DBeaver'da SQL UPDATE (karar senin). Gerisi otomatik.

Kontrol:
  Get-ScheduledTask -TaskName "CNG_Fuar_Pipeline_ETL" | Get-ScheduledTaskInfo
  logs\etl_YYYYMMDD.log  (son satırlar: "ETL başarıyla tamamlandı")
